# Project Glossary

This directory maintains the standardized domain terminology and project-specific concepts for this repository. Its purpose is to eliminate ambiguity and provide single, objective definitions that can be cross-referenced across requirements, architecture decision records (ADRs), source code, and user documentation.

## Guidelines

- **Human-driven curation**: New terms are proposed by humans/domain experts, not generated autonomously by AI agents.
- **Single source of truth**: Each term has its own markdown file created from [TEMPLATE.md](./TEMPLATE.md).
- **Naming convention**: Use lowercase kebab-case for filenames matching the term (e.g., `session-token.md`).
- **Markdown quality**: Adhere to clean Markdown and verify formatting with `markdownlint`.
